# Chenna Siridha — Portfolio Website

A responsive personal portfolio website built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. For development, use the Live Server extension in VS Code.

## Customize
- Edit text and project details in `index.html`.
- Update colors, layout, and responsive styles in `style.css`.
- Mobile navigation and dynamic footer year are handled by `script.js`.

## Before publishing
- Confirm the DRDO internship date and other resume details are accurate.
- Add GitHub links or project demos if you want them shown.
- If you want a profile photo, add one and update the hero section.
- The Google Fonts import requires an internet connection; the site otherwise works as a static website.
